# Base Actions - Cópia

![GitHub Actions](https://img.shields.io/badge/GitHub-Actions-2088FF?logo=github-actions) ![Copy](https://img.shields.io/badge/Status-Copy-yellow.svg)

> Cópia do repositório [base-actions](https://github.com/juninmd/base-actions). Esta é uma réplica do repositório original de GitHub Actions reutilizáveis.

## Sobre

Este repositório é uma **cópia** do `base-actions`, mantendo as mesmas actions compostas para CI/CD. Consulte o repositório original para documentação completa e atualizações.

## Actions Disponíveis

| Action | Descrição |
|--------|-----------|
| `deploy-to-argocd/` | Deploy para ArgoCD |
| `docker-build-push/` | Build e push de imagens Docker |
| `quality-check/` | Verificação de qualidade de código |
| `setup-node-pnpm/` | Setup de ambiente Node.js + pnpm |
| `setup-ollama/` | Setup de ambiente Ollama |

## Nota

Este repositório é uma **cópia de segurança** e pode não estar sincronizado com o original.
